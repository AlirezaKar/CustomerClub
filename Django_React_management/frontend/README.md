# CustomerClub — Management frontend

React (Vite) staff console for shops, branches, products, and offerable flags.

## Development

```bash
npm install
npm run dev
```

Default dev URL: http://127.0.0.1:5001/

Requires the management API at http://127.0.0.1:8000/ (see `../backend/.env`).
